# Hosted Human Protein Atlas Image Cache

This folder contains a cache of source images from the

**Human Protein Atlas (HPA)** — specifically fields of view that HPA no longer

serves since v19. They are hosted here so the PUPS composite JPG

pipeline remains reproducible even after upstream availability changes.
